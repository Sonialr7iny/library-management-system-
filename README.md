Library Management System

Overview

A small Library Management System developed as a team to practice:

- Object-Oriented Programming (OOP)
- Clean Code principles
- Git and GitHub
- Collaborative software development

Features

- Manage books
- Manage members
- Manage loans
- Persist data using JSON
